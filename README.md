## Overview

This portfolio is designed as an interactive engineering workspace rather than a traditional personal website.

Inspired by developer tools, operating systems, and editorial design, it showcases AI projects, software engineering case studies, publications, certifications, and technical thinking through immersive interactions, architectural visualizations, and a terminal-inspired interface.

---

## Features

- 🚀 Interactive boot sequence
- 🖥️ Terminal-inspired portfolio interface
- 🏗️ Engineering-focused project case studies
- 📚 Engineering Journal with publication & certificate preview
- 📄 Built-in PDF viewer
- 🌌 Animated neural network background
- 🔊 Custom Web Audio API sound effects
- 📱 Responsive across desktop, tablet, and mobile
- ⚡ Built with React, TypeScript, and Vite

## Featured Projects

### 🤖 RAG Knowledge Assistant

Production-ready Retrieval-Augmented Generation platform supporting semantic document search, persistent vector storage, multi-provider LLM integration, and secure per-user API key management.

**Stack**

React • TypeScript • FastAPI • ChromaDB • SQLite • Gemini API

---

### 📖 Chronicle

A full-stack publishing and journaling platform emphasizing clean architecture, authentication, scalable data modeling, and modern web engineering.

---

### 🏏 CricShift

AI-powered cricket momentum prediction system leveraging machine learning to detect match momentum shifts and estimate win probability.

---

### 📓 LabPad

Offline-first Progressive Web Application enabling engineering students to securely manage notes and code snippets with automatic synchronization between local storage and Supabase.

---

### ❤️ Interactive Valentine's Experience

A creative frontend engineering project exploring interactive storytelling, state-driven interfaces, micro-interactions, and responsive design using Vanilla JavaScript.

## Getting Started

Clone the repository

```bash
git clone https://github.com/pvndr/pavan-s-portfolio.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Create production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
